## Atualizações futuras

Para enviar novas alterações a partir de uma cópia local autenticada:

```bash
git add .
git commit -m "descrição da alteração"
git push origin main
```

Não armazene senhas ou tokens dentro do projeto. Use Git Credential Manager, chave SSH, GitHub CLI autenticado ou outro método oficial de autenticação.
